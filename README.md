I'm from a OOP-Background. The most functional I ever touched was Rust / Kotlin so this is gonna be fun!

```

3. Zig → Modern systems programming
4. Gleam → Fresh, clean, delightful
5. Haskell → Pure FP challenge
6. Julia → High-performance interpreted
7. Crystal → Rubyesque productivity + native speed
8. Prolog → Totally different thinking
9. OCaml → Industry-grade functional powerhouse
10. Raku → Extremely expressive and fun
```
